_Released July 27, 2026_

This release covers changes after `0xtrails@0.17.0` through `0xtrails@0.17.1`.

A bindings-only release. The `0xtrails` package itself has no source changes.

## Features

- Select the new `EVERLONG` route provider via `RouteProvider.EVERLONG`, added to the `RouteProvider` enum in `@0xtrails/api` and re-exported from `0xtrails`.

## Breaking Changes

None.
